# HealthNest

HealthNest is a college project: a responsive, multi-page wellness website built with HTML and CSS, with a small amount of JavaScript for the dark mode toggle.

## Pages

- **Home** (`index.html`) — wellness landing page with service, product, and pricing sections
- **About** (`about-us.html`) — project brand story, values, and team
- **Services** (`services.html`) — wellness services, plans, and products
- **Contact** (`contact.html`) — contact information and a message form layout

## Built with

- HTML5
- CSS3
- JavaScript (theme toggle)
- Google Fonts (Inter)

## Run locally

No build tools or package installation are required. Clone or download this repository, then open `index.html` in a web browser. Use the navigation links to visit the other pages.
